Demo aid for V MAX Protocol - spawns the real server/client processes. Not a graded deliverable.

Demo tips / coverage notes
  • Auto-reconnect (ADR 0007): kill a server while a client targeting it is still running, then click Start on that same server card — the client's log will show reconnect attempts with growing backoff (1s → 2s → 4s → ...) until it re-registers.
  • Not demoable from this dashboard: protocol version validation (ADR 0009), Seq gap/duplicate detection (ADR 0006), and the 401 branches of PUSH/STATUS for an unregistered node (handlers.ts) — all four require hand-crafted wire bytes, since the reference client only ever sends PUSH/STATUS after a successful REGISTER. See tests/integration.test.ts or docs/adr/0006/0009 to see them exercised.
  • STATUS method: every client now self-checks via STATUS every 3rd PUSH (ADR 0012) — watch any client's log for a few pushes to see it appear, answered 200/registered:true under normal operation.
