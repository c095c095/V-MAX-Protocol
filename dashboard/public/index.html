VMP Dashboard

Demo aid for V MAX Protocol - spawns the real server/client processes. Not a graded deliverable.

Demo tips / coverage notes
  • Auto-reconnect (ADR 0007): kill a server while a client targeting it is still running, then create a new server on the same port — the client's log will show reconnect attempts with growing backoff (1s → 2s → 4s → ...) until it re-registers.
  • Not demoable from this dashboard: protocol version validation (ADR 0009) and Seq gap/duplicate detection (ADR 0006) both require hand-crafted wire bytes that no client spawned here ever sends. See tests/integration.test.ts or docs/adr/0006/0009 to see them exercised.
  • STATUS method: not a dashboard limitation — client.ts never sends a STATUS request in any form, CLI or dashboard-spawned, so 200/401 on that method can't be demoed by any client here.
