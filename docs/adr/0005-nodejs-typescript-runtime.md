# ใช้ Node.js + TypeScript แทน Bun

แม้ Bun จะตรงกับ stack ที่ใช้ประจำ (FarmFlow) และมี syntax กระชับกว่าสำหรับ TCP socket (`Bun.listen()`/`Bun.connect()`) แต่เลือก **Node.js (`net` module) + TypeScript** แทน เพราะ:

1. Node.js ติดตั้งอยู่แทบทุกเครื่องอยู่แล้ว รวมถึงเครื่อง/ห้อง lab ที่อาจใช้อัด vdo demo หรือเครื่องที่อาจารย์ใช้ตรวจโค้ด — ลดความเสี่ยงเรื่อง environment ไม่พร้อมตอน demo
2. อาจารย์ผู้ตรวจคุ้นเคยกับ Node.js มากกว่า Bun แน่นอนกว่า

ทางเลือกที่พิจารณาแต่ไม่เลือก: Bun — ตรงสไตล์การเขียนมากกว่า เขียนกระชับกว่า แต่ความเสี่ยงเรื่อง environment ไม่คุ้มสำหรับงานที่ต้องส่ง demo/รายงานให้อาจารย์ตรวจ
